# Casino Tycoon — 第一版可玩原型 (Godot 4.4, GDScript)

## 怎麼跑
1. 安裝 Godot 4.4(Standard 版即可;4.3 以上應該也能開)。
2. Godot 專案管理員 → 匯入 → 選這個資料夾的 `project.godot`。
3. 按 F5 執行。第一次開啟時編輯器會自動掃描 `class_name`,請等它跑完再執行。

## 操作
| 操作 | 按鍵 |
|---|---|
| 買機台 | 左欄按鈕 → 在地圖左鍵放置(可連續放),右鍵/Esc 取消 |
| 旋轉 | R(機器格 + 座位格,四個方向) |
| 選取機台 | 左鍵點機台(右欄顯示統計、賣出 50%、移動) |
| 暫停 / 1× / 2× | 空白鍵 / 1 / 2 |
| 視角 | WASD 或方向鍵移動,滾輪縮放 |
| 賭局設定 | 右欄 − / ＋(機率與倍率可自由調整,只擋不合法的值) |

## 專案結構
```
core/    規則層(不引用 Node/UI,可無頭測試)
  config.gd           全部可調參數(暫定值集中在這裡)
  machine_*.gd        機台型號(資料驅動)/ 賭局設定 / 場上實例
  gambling_model.gd   賭局數學(RTP、期望利潤、抽結果)
  casino_state.gd     現金、機台、佔用格、帳本、聲望、債務、每日結算
  customer*.gd        顧客資料與行為(AStarGrid2D 尋路)
  simulation.gd       固定步長、暫停、倍速
world/   3D 呈現(地板、機台、顧客、放置預覽、攝影機)
ui/      HUD(全部用程式建立)
tests/   run_tests.gd(單元測試)、smoke_main.gd(整個場景冒煙測試)、calibrate*.gd(校準工具)
```

## 測試(需要 Godot 命令列)
```
godot --headless --path . --import
godot --headless --path . -s res://tests/run_tests.gd      # 47 項檢查 + 經濟報告
godot --headless --path . -s res://tests/smoke_main.gd     # 載入完整場景並自動操作
godot --headless --path . -s res://tests/calibrate.gd      # RTP 掃描
```

## 已實作的規則(對應 v0.3 草案)
- 起始 $5,000、12×12、一天 120 秒、暫停/1×/2×;所有金額用整數「分」。
- 機台全為 1×2(機器 + 座位)、可旋轉;賣出返還 50%;閒置機台可免費移動。
- 賭局:輸 / 標準獎 / 大獎,倍率為「總賠付倍率」(含本金);帳本把賭注、賠付、購買、轉售、租金、罰款分開記。
- 顧客:有本金、停損(輸掉 4 倍賭注離場)、最多等 8 秒、找不到路就算未服務。
- 滿意度依來訪回報率;聲望在顧客離場時即時更新(跌快漲慢);客流 = 16×(R/50)²,無人為上下限。
- 每日租金 $75;負現金只在結算時計數;打手每段負債期間收一次 $100;連續 3 次負結算,或沒機台又買不起 → 遊戲結束。

## 已知問題 / 待校準
- 「割韭菜再補聲望」目前只比正常經營落後約 10%(目標是明顯落後);要再調 α_up/α_down、停損與客流敏感度。
- 預設參數是用 4 台 A 機、30 天模擬粗調的,B 機與更大規模的平衡還沒調。
- 顧客走路中途才被放下的機台擋到路徑時,會穿過機台(不處理,符合「擺錯是玩家的事」)。
- 沒有存檔、擴建、音效、美術(全部是基本幾何體)。
